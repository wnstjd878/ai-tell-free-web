# CARD-TITLES.md — 카드·표·그래프 제목 짓는 법

화면에서 AI 티가 가장 먼저 드러나는 자리가 제목이다. 지시 없이 뽑으면
"어디서 나갔나", "누가 벌어주나" 같은 물음꼴이 나온다. 사람이 만든 화면의
메뉴·표 머리와 결이 어긋나서, 다른 곳을 아무리 다듬어도 화면이 어수선해 보인다.

## 제목은 물음이 아니라 이름이다

카드·접힌 구역·그래프의 제목은 **두 어절 안팎의 명사구**로 짓는다.
"누가 벌어주나" 같은 물음이나 "돈 나갈 일 · 막힌 일" 같은 말투는 쓰지 않는다.
설명이 필요하면 제목 옆 작은 글자(`<small>`)에 한 줄로 붙인다.

| 물음·말투 (안 씀) | 명사구 (씀) |
|---|---|
| 누가 벌어주나 | **가입자별 수익 기여** |
| 돈 나갈 일 · 막힌 일 | **처리 대기 현황** |
| 다음 달 늘릴 수 있는 곳 | **성장 여지** |
| 마진 구성 월별 | **월별 마진 추이** |
| 유입 · 전환 | **마케팅 성과** |
| 회원 1명의 가치 | **회원 생애 가치** |
| 어디서 나갔나 | **이탈 지점** |
| 어디서 들어왔나 | **유입 분석** |
| 어느 구간에서 떠나는가 | **섹션별 도달률** |
| 마진은 어디서 늘고 있나 | **월별 마진 추이** + **성장 여지** |

짓는 법은 둘 중 하나다.

1. `[무엇을 나눈 축]별 + [재는 것]` — 가입자별 수익 기여, 매체별 수익, 월별 마진 추이
2. `[상태] + 현황·추이·분포·여지` — 처리 대기 현황, 지역별 분포

부사·조사·동사가 들어가면 물음이나 문장이 된 것이니 다시 줄인다.

## 왼쪽 메뉴와 같은 말을 쓴다

**메뉴에 같은 이름의 화면이 있으면 그 이름을 그대로 카드 제목에 쓴다.**
도넛 카드를 "어디서 들어왔나"라고 지었더니 왼쪽 메뉴의 "유입 분석"과 어긋난 적이 있다.
이름이 둘이면 보는 사람은 다른 것으로 읽는다.

프로젝트마다 새로 지으면 같은 것을 두 이름으로 부르게 되므로, 흔한 자리는 아래를 그대로 쓴다.

| 자리 | 카드 이름 | 안 쓸 말 |
|---|---|---|
| 지표 카드 묶음 | (제목 없음) | |
| 손댈 일 목록 | **확인이 필요한 일** | 할 일, TODO |
| 방문 추세 | **방문자** | 트래픽, 유입 추이 |
| 매출 추세 | **매출 · 주문** | 세일즈 |
| 월 단위 표 | **일별 현황** | 데일리 리포트 |
| 유입 채널 도넛 | **유입 분석** | 어디서 들어왔나, 채널 비중, 소스 |
| 단계별 이탈 | **전환 흐름** | 퍼널, 유입 퍼널 |
| 최근 목록 | **최근 문의** / **최근 주문** | 최신 내역 |

## 대시보드 색은 그 화면의 메인색을 따른다

공용 부품에 색을 박으면 다음 프로젝트에서 단추만 딴 색으로 뜬다. 실제로 겪은 사고다
(부품에 박아 둔 주황 vs 그 화면의 하늘색).

| 자리 | 색 |
|---|---|
| 기간 단추(눌린 것) | 메인색 `var(--accent)` |
| 매출 막대 | 메인색 + 투명도 0.45 |
| 도넛 첫 조각 | 메인색 |
| 방문자·페이지뷰 선 | 파란 계열 그대로 (두 줄을 갈라 봐야 해서 메인색과 별개로 둔다) |
| 경고 숫자 | 빨강 (메인색과 섞이면 경고가 안 보인다) |

**차트 라이브러리는 CSS 변수를 못 읽는다.** recharts 는 색을 SVG 속성(`fill`·`stroke`)으로
받기 때문에 `var(--accent)` 를 넘기면 아무것도 안 그려진다. `getComputedStyle` 로 값을
꺼내서 넘긴다. 차트를 `next/dynamic` 의 `ssr:false` 로만 그리면 이때 창이 이미 떠 있다.

```tsx
// 일반 요소
background: value === k ? "var(--accent)" : "#fff"

// 차트 안 (SVG)
const c = getComputedStyle(document.documentElement).getPropertyValue("--accent").trim();
<Bar fill={c} fillOpacity={0.45} />
```

## 기계로 잡는다

`tools/screen_copy.py` 가 제목 자리(`card-title`, `admin-card-header`, `fold-t` 클래스와
`<h2>`~`<h4>`)의 물음꼴(`~나`, `~는가`, `~까`, `?`)을 "볼 것"으로 띄운다.
대화창 제목("무료체험을 시작할까요?")처럼 물음이 맞는 자리는 예외 표시를 붙인다.
JSX 태그면 속성으로, 그 밖의 코드 줄이면 줄 끝 주석으로 단다.

```tsx
<h2 data-copy-ok="">무엇을 도와드릴까요?</h2>
LEARN_MORE: "더 알아보기", // copy-ok: 광고 플랫폼이 정한 버튼 이름이라 못 바꾼다
```

파일을 통째로 빼려면 머리 주석에 `screen-copy: off` 를 둔다. 모델에게 넘기는 지시문
파일이 그렇다. 사람이 보는 화면이 아니라 규칙이 다르다.
