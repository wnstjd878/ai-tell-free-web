# WRITING.md — 화면에 나가는 한국어

화면 문구를 쓰기 전에 읽는다. CSS 변수가 색을 정하고 VISUAL-RULES 가 짜임새를 정한다면,
이 문서는 **글자**를 정한다.

## 규칙을 새로 만들지 않는다

한국어에서 AI 티가 나는 패턴은 이미 정리돼 있다. **im-not-ai** (MIT).
https://github.com/epoko77-ai/im-not-ai
`skills/humanize-korean/references/quick-rules.md` 에 10개 분류 70개 패턴이 근거와 함께 있고
`git pull` 로 갱신된다. **여기서 규칙을 다시 쓰지 말고 그 파일을 읽어 쓴다.**

이 문서는 그중 **화면 문구에서 반복해서 걸리는 것만** 추린 것이다.

## 걸리면 고칠 것

| 걸리는 것 | 왜 | 대신 |
|---|---|---|
| 긴 줄표 `—`, 짧은 줄표 `–` | 영어 부가 설명 습관 (im-not-ai J-3) | 쉼표, 괄호, 또는 문장을 나눈다 |
| 줄 머리의 `•` `·` `▶` | 목록 장식 | 줄바꿈이나 번호 |
| `━━` `═══` 같은 강조선 | 화면에서 소음만 된다 | 여백이나 구분선 요소 |
| 그림글자(이모지) | (im-not-ai C-5) | 뺀다. 사용자가 달라고 하면 그때 |
| 혁신적·획기적·차별화된·진정한 | 뜻이 없는 과장 (im-not-ai D-4) | 무엇이 어떻게 달라지는지 사실로 |
| 결론적으로·정리하자면·한마디로 | 결산 상투구 (im-not-ai D-1) | 바로 결론만 |
| 지금 바로 시작하세요·더 알아보기 | 어디에나 있는 단추 문구 | 그 단추가 무엇을 하는지 |
| 손쉽게·간편하게 | 아무것도 안 알려 준다 | 몇 번 만에 되는지 |
| 카드 제목이 물음·말투 ("어디서 나갔나", "누가 벌어주나", "돈 나갈 일 · 막힌 일") | 화면이 어수선하고 메뉴·표 머리와 결이 어긋난다 | 두 어절 명사구 ("이탈 지점", "가입자별 수익 기여", "처리 대기 현황"). 짝 표는 `CARD-TITLES.md` |

문장 안의 가운뎃점(`주문·배송·상품`)은 한국어 표준 부호라 그대로 쓴다. 금지 대상은
목록 머리표로 쓰는 경우다.

## 어디에 적용하나

**적용**: 화면 글자, 단추, 안내문, 오류 문구, 메일·알림 본문, 어드민 화면, 시트·보고서처럼
사람이 읽는 산출물.

**비적용**: 코드 주석, 변수·함수 이름, 서버 기록(`console.*`), 개발자에게 던지는 오류
(`throw new Error`), git 메시지. 그 자리는 정확한 기술 용어를 그대로 쓰는 게 맞다.

## 기계로 잡는다

글로만 적어 두면 지켜지지 않는다. 화면 문구를 훑는 도구를 같이 둔다.

이 묶음의 `tools/screen_copy.py` 가 그 일을 한다.

```bash
python3 tools/screen_copy.py <프로젝트폴더>
python3 tools/screen_copy.py <프로젝트폴더> --strict   # 어휘까지 실패로
```

평소에는 경고로만 본다. **배포 직전에만 `--strict` 로 돌려 실패로 바꾼다.**
옛 프로젝트에는 쌓인 게 많아 처음부터 막으면 배포가 통째로 멈추기 때문이다.
종료 코드는 0 깨끗, 2 볼 것만 있음, 3 고칠 것 있음이라 배포 스크립트에 그대로 물릴 수 있다.

`고칠 것` 은 기호라서 예외가 거의 없다. `볼 것` 은 어휘라서 업계 표준 용어면 그대로 둬도 된다
(광고의 "최적화", B2B 의 "솔루션"처럼 뜻이 정확한 자리). 판단 기준은 하나다.
**그 단어를 빼면 뜻이 안 통하는가.** 통하면 뺀다.

새 화면을 만들면 그 폴더만 지정해 돌려도 된다.

일부러 남기는 자리는 예외 표시를 단다. JSX 태그면 `data-copy-ok=""` 속성, 그 밖의
코드 줄이면 줄 끝에 `// copy-ok: 이유`. 파일 통째로는 머리 주석에 `screen-copy: off`.

## 쓰고 나서 한 번 읽는다

도구가 못 잡는 것이 더 많다. 다 쓴 뒤 소리 내어 읽고 이 셋만 본다.

1. 같은 어미가 세 번 이어지는가 (`~합니다`, `~합니다`, `~합니다`)
2. 문장이 다 비슷한 길이인가. 짧은 문장을 섞는다
3. 안 써도 뜻이 통하는 단어가 있는가

더 깊이 볼 때는 im-not-ai 의 진단 도구(`metrics.py`)나 yoonmoon(https://github.com/amondnet/yoonmoon)
을 쓴다. 둘 다 MIT다.
